Cara publikasi

  1. Selesaikan tulisan dan klik Unduh file .md.
  2. Buka folder content/posts di repositori GitHub.
  3. Pilih Add file → Upload files dan unggah file .md.
  4. Klik Commit changes ke main. Situs akan dibuat ulang oleh GitHub Actions.
